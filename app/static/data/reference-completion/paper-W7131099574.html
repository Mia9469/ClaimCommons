A hardware-adaptive learning algorithm for superlinear-capacity associative memory on memristor crossbars

AI 文本提取候选，尚待人工核对。图像像素未读取；PDF 页码指文件中的页序。

该Article-in-Press提出真实fault/calibration模型上的离线联想记忆训练，并以64dim RRAM证明binary/continuous pattern recall。较大网络容量、scaling、variation和deep-architecture主要属于模型/资源评估，依pattern相关性、噪声criterion和设备预算。同步振荡、连续噪声定义、Jacobian局部/全局条件及缺失Supplementary Notes的energy/convergence信息均保留，不推广生物memory或通用容量定理。
