# 用户路径改进：实现说明

日期：2026-10-18。

依据 `UX_WALKTHROUGH_2026-10-18.md` 实现。本轮改代码、生成静态页面和同步本地镜像；不部署、不修改科学记录、不调用模型、不提交留言。

## 已实现

- 检索改为先筛选单条记录，再聚合论文。论文可以同时显示人工策展和候选，不再以容器的单一状态屏蔽候选。
- 兼容当前分类 ID 和旧分类映射。无依据的记录显式标为待分类；缺少 claim 分类时可以继承论文范围，但仅用于检索。方向允许多重归属，页面明确说明其计数不能相加当作独立总量。
- 统一方向、论文和问题入口的筛选对象，显示当前匹配数量、零结果说明、清除筛选、排序、分页和命中片段。
- 用稳定 paper/claim ID 同步地址，支持选中记录直链、复制链接、刷新定位及浏览器历史导航。保留现有记录 ID，不将展示顺序作为身份。
- 保留论文 → claim → 问题三列图。默认聚焦一篇论文，可切换问题或全部策展记录；按完整标签高度布局，提供滚动、缩放、路径高亮和键盘操作。图中候选不自动升级为核验关系。
- 问题页增加候选原问题的检索归组，与策展问题索引分栏。相同问题文本不等于已建立支持、反驳或独立复现。
- 记录详情补来源、报告、metadata 和定位更正入口；旧记录未拆分的负结果/不可推论字段保留原义并明确标识，不自动重写科学内容。
- 显示已处理文字页、图像是否读取、缺失材料等覆盖信息；不把文本处理完成称为独立验证。
- 英文/中文界面与记录正文语言分开提示。未新增自动译文；没有翻译时明确保留原提取语言。
- 已有阅读报告增加共享导航、目录、返回论文、下载 metadata、稳定来源内编号和纠错操作。原报告正文和 metadata 不改写；建站时补稳定库记录映射。
- PDF 检测控制字符、替换字符、私用字符、CID 占位符与少文字页。异常按页提示，提供本地 PDF 对照入口；继续调用前单独确认读取质量风险。原始提取文本保留，不靠模型猜回公式。
- 读取质量结果进入基础 JSON、提取 metadata、阅读报告及本地核对标志。质量检测是启发式，不能保证公式正确，也没有自动 OCR 或图像阅读。
- 提取工具增加 OpenAI / DeepSeek / 自定义服务预设，显示完整地址、接收服务和文档链接。切换服务清除旧 key 并重置同意状态；不持久化 key。
- 可选连接测试需要单独同意，可能计费，不发送论文。区分常见 HTTP 权限、模型/接口、限流和服务错误；网络与 CORS 错误不能仅靠浏览器异常可靠区分。
- 社区增加本地更正草稿：可带 paper/claim ID、版本和证据位置下载，或去外部服务预填邮件/GitHub 草稿。没有自动发送、发布或入库。
- 留言组件保留现有 GitHub 后端，用双语周边文案解释英文控件，并提供无法加载时的替代入口。没有伪称第三方组件已提供中文翻译。
- 保持六页结构、适中的字体大小和原有配色；增加窄屏布局及导航键盘样式，不另起平行知识库。

## 主要代码入口

- `library-ui.js`：统一筛选、分类兼容、地址状态、详情与聚焦逻辑图。
- `commons-v02.js`：原有双语编辑文案，不再承担旧版检索逻辑。
- `extractor.js`：运行时 PDF 提取器；读取质量及服务配置逻辑已包含在其中。
- `scripts/extractor-ux.inc.js`：此次迁移的提取器辅助逻辑输入，运行时仍以 `extractor.js` 为准。
- `community-ui.js`：本地更正草稿，不写库。
- `report-ui.js` 与 `scripts/enhance-reports.mjs`：报告外壳与来源内编号映射，不改科学内容。
- `scripts/build-site.mjs`、`scripts/site-sections.json`、`scripts/sync-site.mjs`：页面生成及现有本地目录同步。
- `site.js`、`site.css`：共享导航、语言、可访问性和响应式样式。

## 验证与限制

本轮未执行新的语法检查、自动测试或浏览器回归，也没有进行真实 API 或公开发帖测试。前一轮实际复现的问题与截图保留在原试用报告中，不能拿旧截图当作改动后验证。

下一步应在用户授权后复测：Roxin 的候选筛选与各入口计数、记录直链与后退、图节点布局/键盘、异常公式页的质量确认，以及真正生效的手机视口。付费模型与公开提交测试仍需分别明确授权。

这些改动是交互与来源质量防护的实现，不是对现有 5,201 条 AI 候选的新一轮科学审查。
