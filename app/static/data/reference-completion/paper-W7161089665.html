C2 / 直接结果 · classical_kernel_method

作者将 residual correction 定义为 fidelity-style kernel 上的 kernel ridge regression，但实际实验使用经典硬件可计算的闭式 surrogate K(x,x')≈exp(-||x-x'||²/2)cos²(π<x,x'>/2)，而不是执行物理量子电路。Fig 5 给出的名义 ansatz 为6 qubits、3 layers、36 trainable parameters；这些设计数目不是独立实验样本数。
