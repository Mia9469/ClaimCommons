# Contributing to Claim Commons

Thank you for helping build a scientific record that stops where the evidence stops.

## Good first contributions

1. Choose one record marked `needs_curator_review`.
2. Read the linked paper, not only its abstract.
3. Check the claim, evidence summary, scope and non-claim.
4. Open an issue describing the exact field and source passage you want to change.
5. Submit a pull request that changes one bounded scientific decision at a time.

## What a review must say

A useful review identifies the exact claim–evidence link at issue. “Too small”, “not novel” and “not impactful” are not scientific objections here.

Use one of these outcomes:

- `supports_as_scoped`
- `supports_after_clarification`
- `evidence_gap`
- `contradicted`
- `cannot_assess`

## Guardrails

- Do not upload copyrighted PDFs.
- Do not mark a record `author_confirmed` unless the author or a designated representative checked it.
- Do not treat `source_reported` as independent verification.
- Do not infer an individual's contribution from co-authorship.
- Keep possible significance separate from the supported statement.
- Preserve source identifiers and prior versions.

For the complete process, read [Paper → Claim workflow](docs/PAPER_TO_CLAIM_WORKFLOW.md).
