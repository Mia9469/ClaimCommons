# Claim Commons Roadmap

## v0.1 — Local working prototype

- bilingual charter;
- Claim Record JSON Schema;
- browser submission form;
- local SQLite storage;
- claim browsing and detail view;
- lightweight claim-language warnings;
- structured peer-review comments;
- JSON import/export and versioning API.

## v0.2 — Closed alpha, 10–20 researchers

- authentication and ORCID linking;
- contributor-role taxonomy;
- artifact checksum verification;
- moderation queue;
- record version comparison;
- usability study: can readers identify the exact supported claim faster than from a conventional abstract?

## v0.3 — Claim graph

- supports / contradicts / replicates / narrows / generalises / depends_on / supersedes relations;
- claim dependency visualization;
- structured replication records;
- notifications for challenges and supersession.

## v0.4 — Durable scholarly infrastructure

- archival partnership and persistent identifiers;
- interoperable research-object packaging;
- public API and bulk export;
- governance board with student and early-career representation;
- discipline-specific evidence contracts developed openly.

## First success criterion

The first pilot does not need to “replace journals.” It succeeds if researchers can more quickly and reliably answer:

> What exactly was established, by which evidence, under which boundary?
